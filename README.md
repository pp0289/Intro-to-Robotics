# Intro-to-Robotics

ME381: Introduction to Robotics Course Project This repository contains the project work for the "Introduction to Robotics" (ME381) course, under the guidance of Prof. Ashish Dutta. The project covers fundamental concepts in robotics, including motor control, sensor integration, robot navigation, and manipulator kinematics.

🚀 Project Overview This project involved a series of hands-on implementations and analyses on various robotic platforms. The primary goal was to apply theoretical robotics concepts to practical challenges, from controlling simple motors to programming complex autonomous behaviors and analyzing manipulator arm movements.

✨ Key Features & Implementations Motor Control:

Implemented both open-loop and PID control algorithms for DC motors.

Applied control strategies to autonomous mobile robots and industrial manipulator arms.

Autonomous Navigation:

Programmed a mobile robot for autonomous line-following using IR sensors.

Developed algorithms for maze navigation and dynamic obstacle avoidance.

Manipulator Kinematics:

Analyzed the kinematics of both two-link serial and five-bar parallel manipulators.

Successfully performed forward and inverse kinematics calculations for these configurations.

Hardware & Sensor Integration:

Integrated a variety of sensors and actuators into robotic systems, including:

IR Transceivers

Proximity Sensors

Encoders

Stepper Motors

Servo Motors

🛠️ Core Concepts & Technologies Control Systems: PID Control, Open-Loop Control

Sensors: Infrared (IR) Sensors, Proximity Sensors, Encoders

Actuators: DC Motors, Stepper Motors, Servo Motors

Kinematics: Forward Kinematics, Inverse Kinematics

Robot Platforms: Autonomous Mobile Robots, Serial Manipulators, Parallel Manipulators
